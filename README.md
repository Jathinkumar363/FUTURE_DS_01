# FUTURE_DS_01
💊 Medical Store Sales Dashboard Project

Developed an interactive Medical Store Sales Dashboard using Python, Streamlit, Pandas, and Plotly to analyze medicine sales, profit trends, inventory status, and category-wise performance. The dashboard provides real-time business insights through KPIs, charts, and visual analytics.

Key features include sales analysis, top-selling medicines, profit distribution, low-stock alerts, and category-wise revenue tracking. This project helped enhance skills in data visualization, dashboard development, business analytics, and Python programming.

Technologies Used:
• Python
• Streamlit
• Pandas
• Plotly

This project was created as part of a Data Science & Analytics internship portfolio project.
